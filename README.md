# CallScheduler (통화 녹음 자동 분석 및 일정 등록 비서 v3.4)

통화 종료 직후 새로 생성되는 통화 녹음 파일만 실시간 감지하여 AI 음성 인식(STT) 및 약속·할 일·콜백 일정을 추출하고 Google 캘린더에 등록하는 안드로이드 앱입니다.

## 주요 특징 (v3.4)
- **과거 녹음 자동 분석 원천 차단 + 통화 직후 앱 실행 시 새 녹음 누락 방지**: 최초 실행 시 기존 과거 녹음은 모두 기준선(Watermark)으로 제외하며, 통화 종료 직후 앱을 열었을 때 방금 끝난 통화까지 기준선으로 덮어써지는 현상을 완벽히 방지합니다.
- **수동 선택 및 SAF 복사본 원본 통화 일시 보존**: 파일명에 날짜가 없는 녹음을 직접 선택하거나 SAF 폴더에서 가져올 때도 원본 수정 시각(`COLUMN_LAST_MODIFIED`)을 유지하여 '내일', '모레', '금요일' 등 상대 날짜를 정확히 계산합니다.
- **단독 요일 및 주말 한국어 일정 파서 고도화**: '이번 주' 수식어 없이 '금요일 3시', '수요일 오전 11시', '이번 주말'만 말해도 정확한 날짜로 계산합니다.
- **전화번호 완전 제거**: 일정 제목, 상세 요약, 장소 어디에도 전화번호가 노출되지 않으며 오직 통화 상대방 이름만 표시됩니다.
- **지원 파일명 및 확장자**: 삼성 기본 전화(`통화 상대_YYMMDD_HHMMSS.m4a`), SKT T전화·에이닷(`이름_전화번호_YYYYMMDDHHMMSS.m4u`) 등 `.m4u`, `.m4a`, `.amr`, `.mp3`, `.wav`, `.ogg`, `.3gp`, `.aac` 완벽 지원.

## 모바일 환경에서 정식 서명된 APK 빌드 방법 (GitHub Actions 내장)
이 저장소에 코드가 푸시되면 `.github/workflows/main.yml` 워크플로우가 자동으로 실행되어 고정 릴리스 키스토어로 서명된 `CallScheduler-signed-release.apk`를 빌드합니다.
1. GitHub 저장소 상단 **Actions** 탭으로 이동합니다.
2. **Build CallScheduler Signed Release APK** 워크플로우 실행 결과를 클릭한 뒤 하단 **Artifacts**에서 `CallScheduler-signed-release-apk`를 다운로드하면 기존 앱 삭제 없이 바로 덮어쓰기 업데이트 설치할 수 있습니다.
